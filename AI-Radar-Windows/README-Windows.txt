AI Radar Windows Launcher

Files:
- AI-Radar.exe: Windows x64 launcher/server. Double-click starts the local AI news + leaderboard server and opens Microsoft Edge at http://localhost:8080/leaderboard.html.
- AI-Radar.ico: custom AI/news icon used by the desktop shortcut.

Desktop shortcut:
AI Radar - AI 排行榜.lnk

The shortcut currently points to this project's artifacts\AI-Radar.exe. If you move the project folder, recreate the shortcut so it points to the new EXE path.

To stop the background launcher, use Task Manager and end AI-Radar.exe.
